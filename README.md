
# Presentation Video to Notes (PV2N)



[Presentation Video to Notes (PV2N)](https://github.com/nogayama/pv2n) turns recorded presentations into structured, visual notes.



When you watch a recorded lecture or training session, it can be difficult to remember the content later, even if it made sense at the time. You can take notes or capture screenshots while watching, but that manual work makes it harder to focus on understanding the material.



PV2N helps solve this problem by transcribing the audio from a presentation video, saving important frames as images, and generating a Markdown file that includes both the transcript and screenshots.



If you have access to an AI agent, you can also ask it to analyze the generated Markdown and produce explanatory notes that summarize the key points instead of simply reproducing the transcript. PV2N includes a skill for AI agents to support that workflow.



## Installation

```bash
git clone https://github.com/nogayama/pv2n.git
cd pv2n
python -m pip install -e .
```
