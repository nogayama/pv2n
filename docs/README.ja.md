
# Presentation Video to Notes (PV2N)



[Presentation Video to Notes (PV2N)](https://github.com/nogayama/pv2n) は、録画されたプレゼンテーションを、構造化された視覚的なノートに変換するツールです。



プレゼンテーション動画で講演や研修を視聴すると、その場では理解できても、あとから内容を思い出すのは難しいことがあります。メモを取ったり画面をキャプチャしたりしながら視聴する方法もありますが、手作業が多くなり、講演や研修の内容を理解することに集中しにくくなります。



この問題を解決するために、PV2N はプレゼンテーション動画ファイルから音声を文字起こしし、重要なフレームを画像として保存し、文字起こしと画面キャプチャを含む Markdown を作成します。



また、AI エージェントを利用できる場合は、生成された Markdown を分析させ、文字起こしそのものではなく要点をまとめた Markdown 形式の解説ノートを生成することもできます。このツールには、そのための AI エージェント向けスキルが同梱されています。



## インストール

```bash
git clone https://github.com/nogayama/pv2n.git
cd pv2n
python -m pip install -e .
```
